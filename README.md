## What GitHub is used for:

Store code — Keep projects online instead of only on your computer.

Track changes — Git records what changed, when, and who changed it, so you can go back to earlier versions.

Collaborate — Multiple people can work on the same project without constantly sending files back and forth.

Branches — Create a separate version of the project to experiment or develop a feature without affecting the main version.

Pull requests — Propose changes and have other people review them before they become part of the main project.

Bug tracking — Use Issues to report bugs, request features, or organize tasks.

Open-source projects — Publish projects so other people can view, use, contribute to, or modify them.

Automation — GitHub Actions can automatically run tests, build software, deploy websites, etc.

Documentation — Store things like README files, setup instructions, and project documentation alongside the code.
